# 🪐 Graviton CLI (`graviton-cli`)

[![PyPI version](https://img.shields.io/pypi/v/graviton-cli.svg?color=3b82f6)](https://pypi.org/project/graviton-cli/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)

> **"Your code is the center. AI orbits it. The self-hosted, zero-trust AI coding cockpit."**

Graviton is a zero-trust AI coding cockpit and Model Context Protocol (MCP) control plane. It traps AI proposals in memory, maps downstream AST blast radius, provides real-time WebUI diff inspection, and guarantees instant git rollbacks.

---

## ⚡ Installation

Install via pip:

```bash
pip install graviton-cli
```

Or run with `pipx`:

```bash
pipx run graviton-cli start
```

---

## 🚀 Quick Start

```bash
# Start Graviton Engine & Cockpit WebUI
graviton start
```
