# Security Policy 🛡️

Graviton is architected for zero-trust AI code execution. We take security vulnerabilities seriously.

---

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within Graviton or any of its packages, **please DO NOT report it as a public GitHub issue.**

Instead, please send an encrypted or direct email report to:
📧 **`yakkshit@proton.me`**

### Please include:
1. Type of issue (e.g. MCP sandbox bypass, AST traversal flaw, unauthorized WebSocket access, local tunnel spoofing).
2. Full steps to reproduce the vulnerability.
3. Proof-of-concept code or test scenario.
4. Any potential mitigations you have identified.

### Response Timeline
- **Initial Response:** Within 48 hours acknowledging receipt of your report.
- **Status Update:** Within 7 days with a triage assessment and target patch date.
- **Disclosure Policy:** We practice coordinated vulnerability disclosure. We will credit you in the release notes once the patch is published.
